---
title: NFT anchoring overview
description: What it means to anchor a report on-chain and why it matters
---

Anchoring creates a permanent, verifiable on-chain record of the report. The report content is hashed and stored in NFT metadata on Arweave. The NFT itself lives on Solana mainnet.

Anchoring matters because a report anchored on Arweave and Solana cannot be altered or deleted. The content is verifiable by anyone with the mint address.

The NFT metadata JSON stores the structured fields as NFT trait attributes. The raw symptom text is not included in on-chain metadata.

In the current public mint mode, the platform wallet holds the NFT. A user-owned mint mode is on the roadmap.

Anchored reports appear on the public feed, on Magic Eden, and on Tensor.

The platform covers all Solana fees, Arweave storage costs, and image generation costs. Anchoring is free for the user.
