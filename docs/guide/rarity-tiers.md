---
title: Rarity tiers
description: How confidence scores map to NFT rarity tiers
---

When a report is anchored as an NFT, it receives a rarity tier calculated from the confidence score.

| Confidence score | Rarity tier |
|---|---|
| 0 to 20 | Common |
| 21 to 40 | Uncommon |
| 41 to 60 | Rare |
| 61 to 80 | Epic |
| 81 to 100 | Legendary |

The rarity tier is embedded in the NFT metadata as a trait attribute. It is visible on Magic Eden and Tensor. It also influences the visual style of the trading card image.

Rarity is determined by evidence strength, not by randomness. A report with a confidence score of 85 will always be Legendary. There is no random element in rarity assignment.
