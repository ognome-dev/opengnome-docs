---
title: On-chain anchoring modes
description: Current and upcoming anchoring modes
---

## Current mode - Public mint (beta)

The platform wallet pays all fees. The compressed NFT is minted to the platform wallet. The user receives an explorer link, no wallet needed. The report appears on the public feed. 500 bps secondary royalties go to the platform treasury.

## Upcoming mode - Mint to wallet

The user connects a Solana wallet. The NFT is minted directly to the user's wallet address. The user is the on-chain owner. 500 bps royalties route to the user's wallet on secondary sales. Status: planned.
