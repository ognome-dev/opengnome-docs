title: Quick start
description: Get your first signal report in under two minutes
---

## Step 1: Go to opengnome.bio

Open your web browser and navigate to the OpenGnome platform.

## Step 2: Enter your symptom description

Enter a free-text description of your symptoms. Be specific, include duration, include severity, mention what makes it better or worse, and aim for 100-500 characters for best results.

## Step 3: Submit and wait

Click submit. The platform retrieves evidence from PubMed and ClinicalTrials.gov in parallel. This typically takes 5-15 seconds.

## Step 4: Read your signal report

Review the structured report that appears. It includes a primary signal, secondary signals, confidence score, signal strength, and linked sources.

## Step 5: Anchor the report on-chain (optional)

If you want to create a permanent record, choose to anchor the report. This generates an NFT with the report data stored on Solana and Arweave.

## Rate limit note

The platform allows 2 analyses per IP address per UTC day. The limit resets at midnight UTC.
